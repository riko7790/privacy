Questions fréquentes

L'application ne se connecte pas à mon Dolibarr.

Vérifiez que l'URL de votre instance est correcte (ex. : https://mon-dolibarr.com) et que l'API REST est activée dans Dolibarr (Configuration → API). Assurez-vous également que votre clé API est valide.

Où trouver ma clé API Dolibarr ?

Dans Dolibarr, allez dans votre profil utilisateur → onglet API/Services web. Générez ou copiez votre clé API depuis cet écran.

Les données affichées ne sont pas à jour.

Tirez vers le bas sur le tableau de bord pour forcer un rafraîchissement. Les données sont chargées en temps réel depuis votre instance Dolibarr.

L'application collecte-t-elle mes données ?

Non. L'application n'envoie aucune donnée à des serveurs tiers. Vos données transitent uniquement entre votre appareil et votre propre instance Dolibarr. Consultez notre politique de confidentialité pour plus de détails.
